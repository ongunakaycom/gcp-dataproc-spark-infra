The case study

One quickstart, rebuilt like production.

Google's Dataproc quickstart is a few console clicks. This project turns the same outcome into reviewable infrastructure — then proves the story without spending a cent.

01

The brief

Codify the official Dataproc quickstart: enable the APIs, grant the default compute service account the Dataproc Worker role, create example-cluster and run the bundled SparkPi example.

02

The constraint

No billing account and no live project. Every claim had to stay reproducible from a clean clone — which makes static validation, security scanning and this simulation part of the deliverable.

03

The outcome

A validated Terraform module, an IAM binding that prevents a classic first-run failure, six green CI checks and a self-contained case study you can replay below.

Infrastructure as code

Terraform — declarative foundation

A single apply enables three APIs, derives the Compute Engine default service account from the project number, binds roles/dataproc.worker, creates a lifecycle-managed staging bucket and provisions the cluster. No console clicks, no drift.

hashicorp/google 6.x idempotent remote-state ready
terraform apply -auto-approve
